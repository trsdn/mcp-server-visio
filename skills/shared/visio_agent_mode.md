# Working with Visible Visio Sessions

Some users want to watch the automation happen live. Others want the fastest possible background run. Respect that preference.

## When to Use a Visible Session

Prefer visible execution when the user says things like:

- "show me while you work"
- "let me watch"
- "keep Visio visible"
- "debug this interactively"

Prefer background execution when the user says things like:

- "just do it"
- "run quietly"
- "I only need the result"

## Live-Work Pattern

When the current host or command surface supports visible execution:

1. Open the file in a visible session.
2. Narrate major page or shape changes as they happen.
3. Pause only if the workflow requires a user decision.
4. Save and close only after the requested work is complete.

## Good Visible-Session Scenarios

### 1. Building a Diagram from Scratch

- create or open the target file
- create the first page
- add shapes or drop masters in small, reviewable steps
- set text and connector labels
- verify the final structure before closing

### 2. Troubleshooting Layout Problems

- inspect pages and shapes one step at a time
- read key ShapeSheet cells after each edit
- explain what changed and why

### 3. Guided Review

- open the diagram visibly
- list pages and read the target page
- walk the user through the structure, labels, and main relationships

## Practical Rule

Visible mode is for trust and debugging. Background mode is for speed. Match the user's preference, then keep the workflow incremental and well explained.
