# VisioMcp.Core

Core Visio automation logic for VisioMcp.

This internal library contains the shared command layer used by `VisioMcp.McpServer` and `VisioMcp.CLI` for the current Visio MVP surface: sessions, pages, shapes, text, ShapeSheet cells, stencil workflows, and supporting design data.

It is not intended for direct end-user consumption.

## Requirements

- Windows with Microsoft Visio desktop installed
- .NET 10.0+

## Documentation

See the [main repository](https://github.com/trsdn/mcp-server-visio) for installation and end-user guidance.
